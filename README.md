# Scan Tailor

Herramienta de post-procesamiento interactiva para páginas escaneadas.

## Modernización en Curso

Se está migrando la arquitectura de **Qt5 → wxWidgets + C++23**:

- ✅ Eliminación de dependencias Boost (completado)
- 🔄 Modernización a C++23 (análisis)
- 🔄 Migración de Qt5 a wxWidgets (análisis)
